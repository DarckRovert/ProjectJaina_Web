# Política de Seguridad — Project JAIna Web

Este documento describe la política de seguridad para el portal oficial de **Project JAIna (WotLK 3.3.5a)**.

## Versiones Soportadas

Actualmente se proporciona soporte de seguridad para las siguientes versiones:

| Versión | Soportada |
| ------- | --------- |
| 2.x.x   | ✅         |
| 1.x.x   | ⚠️         |
| < 1.0.0 | ❌         |

## Reporte de Vulnerabilidades

Si descubres una vulnerabilidad de seguridad en este portal o en los endpoints de la API, por favor envía un reporte confidencial a **DarckRovert** o al equipo de ingeniería a través de nuestro issue tracker privado o mensaje directo.

Por favor, no abras un Issue público para reportar una vulnerabilidad crítica de seguridad.

## Alcance

Esta política cubre el código fuente del portal web alojado en este repositorio y sus integraciones con el backend SRP6. Los addons individuales del ecosistema tienen sus propias políticas de seguridad en sus respectivos repositorios.
